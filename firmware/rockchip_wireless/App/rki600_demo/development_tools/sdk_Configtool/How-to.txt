关于RKConfigtool的说明：
	
	RKConfigtool工具是为了方便配置NanoX系列工程而做的配置工具。
	
使用方法
		将RKConfigtool.exe 放在SDK 工程目录下，双击运行该exe程序，根据项目需要配置SDK所需的
		模块或修改相应的宏定义数值。
		RKConfigtool程序会根据各个不同模块目录下是否包含config文件来扫描生成配置树。所以，需要使该模块可配置
		需在相应模块下定义config配置文件。
		
	config文件的结构定义。
		config + Module Name 定义一个模块
		end config 结束模块定义
		
		在end config 之前需要对该模块进行详细的配置说明，其中，
		“bool” 关键字表明该config是可选择的，bool关键字后可以跟说明性的字符串；
		“default” 关键字表示默认值，“y” 表示默认支持，“n”表示不支持。
		“---help---” 关键字是i对Module Name 的一些说明性文字。对该模块的详细说明可以在该关键字下面列出。
		
		subconfig + sub Module Name 表示定义一个子模块。
		end subconfig 结束模块定义
		这end subconfig 之前需要对该子模块进行详细的配置说明，其中，
		“deponds on” + Module Name 表明该子模块是定义在Module Name下。
		“bool” 关键字表明该sub config是可选择的，bool关键字后可以跟说明性的字符串；
		“string” 表明该sub config 是一个字符串。后面可跟说明性字符串。
		“int” 表明该sub config 定义为一个整形数值。后面可跟说明性字符串。
		“hex” 表明该sub config 定义为一个十六进制数值。后面可跟说明性字符串。
		
		“default” 关键字表示默认值，如果前面类型是“bool”，其值为“y” 表示默认支持，“n”表示不支持。
									“string”, 后面跟定义的字符串
									“int”或者“hex”，后面跟定义数值。
		
config 文件定义举例：以usb模块为例
			config usb
			bool "support usb drive ,balabalabala..."
			default y
			---help---
				support usb
				balabalabala
				balabalabala......
			subconfig usb_msc
				deponds on usb
				int "support usb_msc,..."
				default 100000
			end subconfig
			
			subconfig usb_otg
				deponds on usb
				string "support usb_otg,..."
				default sssssssss
			end subconfig	
			
			subconfig usb_audio
				deponds on usb
				bool "support usb_audio,..."
				default y
			end subconfig
				
			subconfig usb_serial
				deponds on usb
				bool "support usb_serial,..."
				default y
			end subconfig

			subconfig usb_xxx
				deponds on usb
				hex "support usb_test,..."
				default 0xffffcccc
			end subconfig	
		end config
